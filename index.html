설정 및 데이터 관리

실시간 자동조회 프록시 (선택)

GitHub Pages는 정적 웹페이지라 브라우저 보안(CORS) 때문에 도서관 사이트 내용을 직접 읽어올 수 없습니다.
함께 제공된 cloudflare-worker/worker.js를 무료 Cloudflare Workers에 배포하고 URL을 입력하면, 교보문고·예스24 소장 여부와 대출 가능 권수를 앱 안에서 바로 조회합니다.

스마트폰 앱으로 설치하기 (PWA)

  • 안드로이드 (크롬/삼성 인터넷): 메뉴(⋮) → 홈 화면에 추가 또는 앱 설치
  • 아이폰 (사파리): 하단 공유 버튼(□↑) → 홈 화면에 추가

데이터 백업 및 복원

등록한 도서관 목록과 위시리스트를 JSON 파일로 내보내거나 가져올 수 있습니다.
