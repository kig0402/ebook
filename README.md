# 내 전자도서관 통합검색 (PWA)

교보문고 전자도서관, 부커스(Bookers), 예스24 전자도서관에 흩어져 있는 지역도서관을 한곳에 등록하고, 책 제목/저자로 통합 검색할 수 있는 스마트폰용 웹앱입니다.

- 배포 주소: `https://kig0402.github.io/ebook`

## 주요 기능
1. **내 도서관 등록 및 관리**: 교보문고, 부커스, 예스24별 지역도서관을 추천 목록에서 원클릭으로 추가하거나 직접 URL 입력으로 등록
2. **통합검색**: 검색어 입력 시 내가 등록한 모든 도서관의 검색 결과 페이지로 바로 연결
3. **실시간 소장 여부 조회(선택)**: `cloudflare-worker/worker.js`를 Cloudflare Workers 무료 플랜에 배포하고 앱 설정에 URL을 입력하면 교보문고·예스24 소장 여부를 앱 안에서 바로 파싱하여 표시
4. **스마트폰 앱 설치(PWA)**: 안드로이드 크롬 / 아이폰 사파리에서 "홈 화면에 추가"로 앱처럼 사용 가능
